# Cartex Technologies Ltd – ISO/IEC 27001:2022 Gap Analysis

This project presents an initial gap analysis of Cartex Technologies Ltd against selected requirements of ISO/IEC 27001:2022. It identifies six information-security improvement areas, assesses their implementation status and priority, and recommends practical remediation actions to strengthen the organisation's Information Security Management System (ISMS).

## Project Overview

### Project Background

Cartex Technologies Ltd is a technology company with approximately 120 employees. The organisation has established some security practices, but these are not yet integrated into a formally defined Information Security Management System.

The purpose of this project was to compare the organisation's current security practices with selected ISO/IEC 27001:2022 requirements, identify gaps and recommend improvements.

### Project Objectives

- Conduct an ISO/IEC 27001:2022 gap analysis.
- Identify information-security weaknesses.
- Map identified gaps to relevant Annex A controls and Clause 4.3.
- Assess implementation status and remediation priorities.
- Recommend corrective actions and accountable owners.
- Develop an action plan to improve information security management.
- Draft a proposed ISMS scope statement.

### Dashboard Overview

The assessment identified six improvement areas:

- 2 Not Implemented.
- 4 Partially Implemented.
- 4 High Priority.

### Proposed ISMS Scope

The proposed ISMS covers Cartex Technologies Ltd's digital platform and services supporting sales, inventory, customer information and payments.

It includes employees, business processes, information assets, cloud applications, company laptops and supporting systems across the main office and remote-working environments.

The proposed scope requires management review and approval.

1. **Reviewed the organisation's security environment:** Examined the case-study scenario and existing security practices.

2. **Reviewed ISO/IEC 27001:2022 requirements:** Identified relevant Annex A controls and ISMS requirements.

3. **Identified six security gaps:** Reviewed asset management, security awareness, physical access, access rights, MFA and ISMS scope.

4. **Mapped the gaps to ISO controls:** Recorded the relevant control references and categories.

5. **Assessed implementation status:** Classified each gap as Not Implemented or Partially Implemented.

## Results and Findings

### Gap Analysis Register

| ID | Identified Gap | ISO Reference | Status | Priority |
|---|---|---|---|---|
| 1 | No central information asset inventory | A.5.9 | Not Implemented | High |
| 2 | Security training only at onboarding | A.6.3 | Partially Implemented | Medium |
| 3 | No formal physical access controls for key areas | A.7.2 | Partially Implemented | Medium |
| 4 | Access not reviewed promptly after role changes | A.5.18 | Partially Implemented | High |
| 5 | MFA not consistently implemented | A.8.5 | Partially Implemented | High |
| 6 | ISMS scope not formally defined | Clause 4.3 | Not Implemented | High |

![ISO 27001 Gap Analysis Register](screenshots/02-gap-analysis-register.png)

### Key Findings

- **Asset Management:** No central inventory of important information assets.
- **Security Awareness:** No regular refresher training for existing employees.
- **Physical Security:** Formal access controls for sensitive areas require improvement.
- **Access Management:** Employee access rights are not always reviewed after role changes.
- **Authentication:** MFA is not consistently applied across relevant systems.
- **ISMS Scope:** The organisation has not formally approved its ISMS boundaries.

### Existing Security Practices

The assessment also identified positive security practices:

- Management-approved security policy.
- Employee password rules.
- MFA on some cloud applications.
- Antivirus on company laptops.
- Regular backups.
- Security awareness training for new employees.
- Restricted access to the main office.

### Recommended Remediation Plan

| Improvement Area | Recommended Action | Suggested Owner | Target |
|---|---|---|---|
| Asset Management | Create a central asset register and assign asset owners. | IT / Asset Owner | First 30 days |
| Security Awareness | Introduce regular refresher training. | HR / Security Awareness Owner | First 60 days |
| Physical Security | Define restricted areas and review authorised access. | Facilities / Security Owner | First 60 days |
| Access Management | Introduce access reviews during employee role changes. | IT / System Owners + HR | First 30 days |
| MFA | Expand MFA coverage across important systems and accounts. | IT / Identity and Access Owner | First 30 days |
| ISMS Scope | Document and obtain approval for ISMS boundaries. | Senior Management / ISMS Lead | First 30 days |
